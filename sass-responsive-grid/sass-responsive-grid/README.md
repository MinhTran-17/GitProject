# Responsive Grid - Refactor CSS to SASS

Bài thực hành tái cấu trúc CSS của mẫu Responsive Grid thành SCSS.

## Cấu trúc
- `responsive_grid.html`: trang HTML
- `scss/abstracts`: biến và mixin dùng chung
- `scss/base`: thiết lập cơ bản
- `scss/components`: kiểu lưới và responsive
- `css/main.css`: CSS biên dịch để trình duyệt sử dụng

## Chạy
```bash
npm install
npm run sass
```

Mở `responsive_grid.html` bằng trình duyệt. Khi chỉnh sửa SCSS, chạy `npm run sass` để cập nhật CSS.
