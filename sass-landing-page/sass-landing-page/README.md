# Tái cấu trúc Landing Page bằng SASS

Bài thực hành áp dụng SASS/SCSS cho các phần navigation/header, sản phẩm nổi bật, thống kê và footer.

## Kiến thức SASS áp dụng
- Variables: màu sắc, font, breakpoint, khoảng cách.
- Nesting: nhóm CSS theo component.
- Mixins: tái sử dụng container, button và tiêu đề.
- Partials và `@use`: chia mã nguồn thành các file theo chức năng.
- Responsive: media query cho màn hình nhỏ.

## Chạy dự án
```bash
npm install
npm run sass
```

Mở `index.html` trong trình duyệt. CSS đã biên dịch nằm ở `css/main.css`.
Lưu ý: đây là bản landing page minh họa tái cấu trúc SASS theo các phần yêu cầu; nếu cần giữ nguyên tuyệt đối mẫu thiết kế Template đã làm trước đó, hãy thay nội dung/style bằng mã nguồn gốc của bạn.
